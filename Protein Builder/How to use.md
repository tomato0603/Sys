# Protein Builder — 使い方

`protein_builder.html` をダブルクリックしてブラウザで開くだけで動きます。
サーバもインストールも不要の単一 HTML ファイルです（PDB 検索のときだけインターネットに接続します）。

**画面右上の「？」**が 3 枚のガイドになっています。
「1. 配列を集める」「2. 繋ぎ合わせる」「3. 出力」で 1 枚ずつ、右下の**「次へ →」**で送れます（← で戻る、下の点で飛ぶ）。
**この文書はその詳しい版**です。困ったときはこちらを見てください。

---

## 1. 配列を集める

配列は「ライブラリ」に貯めます。入口は 4 つです。

| 方法 | 使いどころ |
|---|---|
| **キーワード検索** | `ankyrin repeat domain` のような語で RCSB PDB 全文検索。名称・生物種・長さ・UniProt ID を見て「＋ 追加」 |
| **PDB ID 直接** | `4O6X, 1AA2` のようにまとめて取得。`4O6X_1` と entity まで指定してもよい |
| **ファイル読み込み** | ApE（.ape）・GenBank（.gb / .gbk）・FASTA をドロップ |

配列は PDB の Web API から直接取り込むので、ファイルを落としてくる必要はありません。

読み込んだファイルは、いずれも**まず候補一覧に出ます**。「＋ 追加」で必要なものだけライブラリに入れ、
**「削除」**でその候補を一覧から消せます（削除はライブラリには影響しません。同じファイルを読み直せば戻ります）。

### ApE（.ape）／ GenBank

**ApE で印を付けた領域（Feature）がそのまま候補になります。** CDS も misc_feature も一覧に出るので、
「ここが ANK リピート」と注釈しておけば、それを選んで繋げられます。

| 表示 | 意味 |
|---|---|
| 種別 | `CDS` / `misc_feature` など、ApE 上の Feature の種類 |
| 位置 | **ApE で見えている数字そのまま**。突き合わせて確認できます |
| 向き | `＋` 順鎖 ／ `−` 逆鎖（相補鎖から翻訳しています） |

翻訳の規則は次のとおりです。

- **CDS** — `/codon_start` を反映して塩基配列から翻訳し直します。ファイルに書かれた `/translation` は使いません。
  ApE で塩基を編集した後に `/translation` が古いまま残ることがあるためです。食い違うと**「ファイルの /translation と食い違います」**と表示します
- **CDS 以外** — 領域の先頭から 3 文字ずつ翻訳します。読み枠の情報が無いためで、
  途中に終止コドンが出た場合は**「途中に終止コドンがあります」**と表示します（読み枠が違う手がかりになります）

**環状かどうかはファイルの `LOCUS` 行に従います。**推測はしません。原点をまたぐ領域（`join(733..1149,1..300)` のような書き方）も
そのまま扱え、一覧に**「原点またぎ」**と表示されます。

`source`（全長）は候補から除いています。注釈が 1 つも無いファイルは読み込まず、その旨をお伝えします。

`sample_plasmid.gb` は、原点をまたぐ CDS と逆鎖の CDS を仕込んだ動作確認用のサンプルです。

### FASTA

**アミノ酸配列のみ扱います。**
プラスミドは ApE（.ape）または GenBank 形式でお願いします。

### ドメインライブラリの見方

| 列 | 内容 |
|---|---|
| （色） | **追加したときに自動で決まります**（下の「色の規則」→ 当たらなければ、まだ使われていない色）。左端の四角にマウスを乗せると変更できます。**一覧の色のほか、右端の四角から好きな色も選べます。**この色が繋ぎ合わせるタブと出力の色分けにそのまま使われます |
| 名称 | **クリックするとパネルが開き、名前・配列・メモをその場で直せます。**名前や配列を変えると、それを使っている Build の表示も同時に変わります |
| **メモ** | 配列ごとの覚え書き。由来・使いどころ・注意点など自由に。書くと一覧の名前の下と、繋ぎ合わせるタブの左パレットに出ます |
| 由来 | PDB / ApE・GenBank / FASTA / 手入力 |
| **使用中** | **その配列を使っている Build の名前**が並びます。使っていなければ `—` |
| 長さ | アミノ酸の数 |
| **追加日** | ライブラリに入れた日 |

一覧が長くなっても、**項目名の行（名前・由来・使用中・長さ・配列・追加日）は画面の上に貼り付いたまま**です。
下までスクロールしても、どの列が何なのか分からなくなりません。リンカー一覧やシステムリクエストの表も同じです。

**絞り込み**と**並べ替え**は一覧の上で指定します。
絞り込みは**名称・メモ・配列**を見ます（小文字で入れても、空白が入っていても構いません）。
メモに書いた日本語でも探せます。
**絞り込み中はアーカイブ済みの配列も探します。**「アーカイブも表示」のチェックが外れていても、
検索に一致すれば出てきます（アーカイブの印が付きます）。探しているものが隠れていては見つけられないためです。
並べ替えは 追加日 / 名前 / 長さ / 配列 の 4 通りで、「降順」のチェックで昇順・降順を切り替えます。

同じ絞り込みは「2. 繋ぎ合わせる」の左パレット（ドメイン）にも付いています。

「使用中」は保存された情報から毎回計算しているので、**実際の状態とずれることがありません。**
Build から要素を外せば表示も消え、Build の名前を変えれば表示も変わります。

### 色の規則 — 名前で色を決める

ドメインライブラリの下の**「色の規則」**を開くと、**「名前にこの文字が入っていたらこの色」**という決まりを作れます。
はじめから **`Tag` → 青（#4E67C8）** が入っています。

- 追加したとき、**上から順に照合し、最初に当たった色**を使います。↑ ↓ で順番を変えられます
- どれにも当たらなければ、**まだ使われていない色**が配られます（従来どおり）
- **大文字小文字は区別しません**（`Tag` / `tag` / `TAG` が同じ）
- 見るのは**名前だけ**です。配列やメモは見ません
- 各行に「いま何件に当たるか」が出ます
- 規則はバックアップの `.json` に入ります

**規則を変えても、すでに入っている配列の色はそのままです。**
まとめて揃えたいときだけ**「いまある配列にも当てはめる」**を押してください。
自動で走らせると、既存の Build の色分けが黙って変わってしまうためです
（このボタンを押した場合は、手で選んだ色も規則に当たれば上書きされます）。

### 配色について

色は PowerPoint テーマ**「スリップストリーム」**から取っています。

ただし**テーマの色をそのまま使うと、白地の配列表示で文字が読めません**（黄緑 `#A7EA52` は白の上で 1.44:1）。
**色相はそのままに、白地で 4.5:1 に届く明度まで落として**います。

| 色味 | 採用値 | テーマの元の値 |
|---|---|---|
| 青 | `#4E67C8` | `#4E67C8`（そのまま） |
| 水色 | `#0D80A9` | `#5ECCF3` |
| 黄緑 | `#518410` | `#A7EA52` |
| 青緑 | `#28856C` | `#5DCEAF` |
| 橙 | `#C55400` | `#FF8021` |
| 赤 | `#E42D0F` | `#F14124` |
| 濃紺 | `#212745` | `#212745`（そのまま） |

7 色なのは、**明度を落とすと見分けがつかなくなる組み合わせを外した**ためです
（緑 `#56C7AA` は青緑と色相差 1 度、空色 `#59A8D1` は水色と 5 度しか違いませんでした）。

### リンカーライブラリ

リンカーも**リンカーライブラリ**で管理します（「1. 配列を集める」の下部）。ドメインライブラリとは別の一覧です。

| 列 | 内容 |
|---|---|
| 名称 | その場で直せます |
| 配列 | その場で直せます。空白や小文字は自動で整えます |
| **メモ** | リンカーごとの覚え書き。用途や切断部位など自由に |
| 追加日 | 追加した日。あとから中身を直すと「更新 ○○」も出ます |

- 上の欄に**名称・配列・メモ**を入れて「追加」
- 右端の数字は、**その配列を使っている Build の数**です
- 「削除」で一覧から外します。**すでに Build に入れたものは残ります**（Build の中のリンカーは配列そのものを持っているため）
- 並べ替えは 追加日 / 名称 / 長さ の 3 通り

はじめから 18 種類（柔軟・剛直リンカー、TEV や 3C の切断部位、His×6 や FLAG などのタグ）が入っていて、
それぞれに使い分けの短いメモが付いています。不要なら書き換えても削除しても構いません。

リンカーの絞り込みも**名称・メモ・配列**を見ます。

**繋ぎ合わせるタブでは、Build の右側に同じリンカーの一覧が出ます。**
ドメインのライブラリ（左側）と同じで、「＋」で選択中の Build の末尾に入ります。
メモもそこに表示されるので、どれを使うか迷ったときの手がかりになります。上の欄で名称や配列から絞り込めます。

### アーカイブ — 使わないものを片付ける

使わなくなった配列や、作り終えた Build は**「アーカイブ」**で一覧から外せます。**削除ではありません。**

| 対象 | 操作する場所 |
|---|---|
| **配列（ドメイン・リンカー）** | **「1. 配列を集める」** — 各行の「アーカイブ」ボタンと、見出し横の「アーカイブも表示」 |
| **Build** | **「2. 繋ぎ合わせる」と「3. 出力」の両方** — 各 Build の「アーカイブ」ボタンと、「アーカイブも表示」 |

**Build のアーカイブは 2 つのタブで連動します。**どちらで片付けても、どちらで戻しても同じです。
「アーカイブも表示」のチェックも共通で、片方を入れるともう片方も入ります。

- 一覧・パレット・出力タブから外れ、一括保存の対象からも外れます
- **配列そのものは消えないので、それを使っている Build はそのまま動きます**
- **「アーカイブも表示」**にチェックを入れると現れ、「戻す」で元に戻ります。
  配列の場合、**アーカイブ済みは一覧の下にまとめて並びます**（並べ替えを変えても末尾のまま）
- アーカイブ済みの Build は**薄く出て、「配列をコピー」と「FASTA を保存」は出ません。**「戻す」だけです
- **配列が入っていない Build もアーカイブできます。**その場合も出力タブに出るので、戻せなくなることはありません
- アーカイブした日付が表示されます

使用中の配列でもそのままアーカイブできます（Build は壊れません）。
アーカイブ済みの Build は「使用中」に数えません。片付けたものを現役の使用状況に混ぜないためです。

## 2. 繋ぎ合わせる

画面の**中央が作業台**です。青い枠で囲まれた中が「Build を組む」場所で、
見出しに**いま何本作っているか**が数と目盛（■）で出ます。アーカイブ済みは数に入りません。

**Build** は何個でも並行して作れます。

**編集対象は、その Build の枠の中をどこでもクリックすれば選べます。**
名前の欄をクリックした場合は、選択と同時にそのまま名前を編集できます。
左の丸（ラジオボタン）は**いまどれが選ばれているかの表示**で、直接押しても選べます。
選び直しても画面は作り直されないので、**名前を打っている途中でも文字は消えません。**

**「＋ Build」で作った Build は、ボタンのすぐ下に出ます。**新しいものが上、古いものが下の順です。
Build がいくつあっても、作った直後にそのまま書き始められます。
**出力タブと FASTA の一括ダウンロードも同じ順**（新しいものが先）に並びます。

**名前は自動で付きます。** ドメインを足す・外す・並べ替えるたびに、ドメイン名を繋いだ名前
（`ANK_repeat-BETA-SPECTRIN` のような形）に更新され、「自動」の印が付きます。
**一度でも手で書き換えると、それ以降は自動更新をやめてあなたの名前を保ちます**（印も消えます）。
リンカーは名前に入りません。

**「複製」で作ったものは、元の Build のすぐ下に入ります。**元と見比べるのにスクロールが要りません。

**複製すると末尾に `copy` が付きます。**`X copy` をさらに複製すれば `X copy copy` です。
**同じ Build をもう一度複製すると `copy2`、`copy3` … と番号が付きます。**同名の Build は作られません
（別々に作った Build がたまたま同じ構成になった場合も、`ANK` と `ANK2` のように分かれます）。

自動名の Build を複製した場合、その後ドメインを足したり外したりしても**名前は追随し、`copy` は残ります**
（`ANK-SPEC copy` → ドメインを入れ替えると `ANK-GFP copy`）。

> **名前の末尾に付く数字には 2 通りの意味があります。**
> `copy2` は「**自分で作った写しの 2 個目**」、`(2)` は「**中身は別物なのに名前がぶつかった**」です
> （`(2)` はライブラリの取り込みで出ます）。似た見た目ですが、意味が違うので揃えていません。

- **左のドメイン一覧は名前の A–Z 順、右のリンカー一覧は短い順**に並びます（長さが同じものは名称順）。
  絞り込んでも順番は変わらないので、探す位置がいつも同じです
- 左のパレットは**名称をクリックすると配列が開きます**（もう一度で閉じます。ここでは編集できません）。
  **メモを書いてあれば名前の下に出ます**ので、どれを使うか迷ったときの手がかりになります
- 左のパレットで **＋** を押すと、選択中の Build の末尾に追加されます。
  選択中の Build がアーカイブ中のときは、**編集できる Build に自動で移って追加します**
  （どれもアーカイブ中なら新しい Build を作ります）
  **ライブラリは画面に固定される**ので、Build が増えて下にスクロールしても見えたままです
- **▾ / ▸** で Build をたたむと、名前と長さだけのバナーになります。
  上部の「すべてたたむ」「すべて開く」でまとめて切り替えられます
- 並べ替えは **⠿ を掴んで上下にドラッグ**、または **↑ ↓** で。
  ドラッグ中は挿入される位置に線が出ます。行と行のあいだにも、一番下の余白にも落とせます。
  掴めるのは ⠿ だけなので、残基や配列の入力欄はふつうに選択・編集できます
- **残基 ○ – ○** でドメインだけを切り出せます（例：末尾の `HHHHHH` を外す、ANK リピートだけ取る）。
  行の下に**切る位置が見えるプレビュー**が出ます。`RMA|IVADHLG … 77 … ISGTRSF|ADE` のように、
  `|` が切れ目、**濃い部分が残る残基**、薄い部分が外れる残基です。数字は省略した残基数。
  見せる残基数は選択範囲の長さに合わせて自動で決まり、**数値を打っている最中も追従します**
- **リンカー／タグを追加** — `(GGGGS)×3`（柔軟）、`(EAAAK)×3`（剛直）、XTEN、TEV・3C・Thrombin 切断部位、His×6 / FLAG / HA / Myc / Strep-tag II などのプリセット
- **自由入力** — 任意の配列を要素として挿入。挿入後もその場で編集できます

### リンカーを足す

画面は左から **ドメインのライブラリ / Build / リンカーの一覧** の 3 列です。

- **右の一覧の「＋」** — そのリンカーを Build の末尾に入れます
- **「追加」**（Build 内の自由入力欄） — 一度きりの配列をその場で入れます（ライブラリには残りません）
- **「ライブラリに保存」** — 自由入力した配列に名称を付けて、リンカーライブラリに加えます

リンカーライブラリはバックアップにも含まれるので、別の端末に移すときも一緒に運べます。
一覧の管理（メモの編集・削除・並べ替え）は「1. 配列を集める」のリンカーライブラリで行います。

## 3. 出力

Build ごとに、色分け表示、長さ、分子量、要素数が出ます。**要素数はドメインの数で、リンカーは含みません。**
色分けの凡例では、**ドメインは四角（■）、リンカーは三角（▲）**で示します。色だけでなく形でも見分けられます。色は**ライブラリの色がそのまま使われます**（並べ替えても変わりません）。

- **配列をコピー** — ヘッダも改行もない生の 1 行配列
- **FASTA を保存** — ヘッダに構成（要素名と各長さ）が入ります。
  **ファイル名には日付が入ります**（`ANK-GS3-SPEC_2026-08-23.fasta`）。同じ Build を何度保存しても上書きされません
- **全 Build を FASTA でダウンロード** — まとめて保存します

## ライブラリと保存について

**配列ライブラリはこの端末にひとつだけ**です。すべての Build が同じライブラリを共有するので、
一度集めた配列はプロジェクトを問わず使い回せます。切り替えの操作はありません。

### バックアップ

画面上部に、最終バックアップ日が常に表示されます。

- `最終バックアップ日 2026-08-11（12 日前）`
- `まだバックアップしていません`

前回のバックアップ以降に変更があるあいだは、**右上の「SYSTEM SAVE (.json)」ボタンが色付きになります。**
保存すると元の見た目に戻るので、保存し忘れに気づけます。

内容はブラウザに自動保存されますが、**ブラウザの「閲覧データを消去」で消えます。**
節目で**画面右上の「SYSTEM SAVE (.json)」**を押してください。ヘッダーは常に見えているので、どのタブからでも押せます。
**「すべて消去」は画面右上の「⋯」の中**にあります。取り消せない操作なので、普段は隠してあります。
**バックアップが済んでいないあいだは実行できません。**
未保存の変更があるときは「先に SYSTEM SAVE を押してください」と出るだけで、何も消えません。
保存済みのときだけ、確認のダイアログを経て消去できます。
ファイル名には日付が入るので（`protein_builder_backup_2026-08-23.json`）、上書きされず世代が残ります。

`file://` で開いた場合、ブラウザによっては自動保存が使えません。そのときは警告が出るので、必ずバックアップを取ってください。

### SYSTEM UPLOAD (.json)

**「取り込む」**（既定）と**「置き換える」**を選べます。

- **取り込む** — いまの内容は消えません。ファイルの中身が足されます。ふだんはこちら
- **置き換える** — いまの内容をすべて捨てて、ファイルの中身にします。復元したいときだけ

同じ配列が両方にある場合は 1 つに統合されます。名前が食い違うときは、どちらを残すか確認画面が出ます。
**メモは手元のものが優先されます。**手元が空のときだけ、読み込んだ側のメモが入ります（書いたメモが黙って消えないようにするためです）。

### 名前が重なったとき

| 状況 | 動き |
|---|---|
| 同じ配列・同じ名前 | 何も聞かずに 1 つに統合します |
| 同じ配列・名前が違う | **どちらの名前を残すか聞きます**（既定は手元の名前） |
| 配列が違う・名前が同じ | **両方残すか、読み込まないかを聞きます** |
| 配列も名前も違う | そのまま追加します |

この規則は、PDB からの追加・FASTA の読み込み・手入力・バックアップの読み込みで共通です。
確認画面で「やめる」を押すと、その読み込みは**まるごと取り消されます**（一部だけ取り込まれた状態にはなりません）。

## システムリクエスト

画面の一番下（データの保管の下）に、**直してほしいこと・足してほしいことを書き溜めておく欄**があります。

- 上の欄に書いて「追加」。記入した順に並びます
- **どのタブを開いているときに書いたか**も一緒に記録され、コピーした文に日付と並べて載ります
  （一覧には出ません。Claude が状況を掴むためのものです）

### 配列でない文字の警告

**AlphaFold が受け取れるのは標準 20 種のアミノ酸だけ**です。
それ以外の文字（`X` 不明、`B` `Z` `J` あいまい、`U` セレノシステイン、`O` ピロリシンなど）が入っていると、
**⚠ の印が付き、どの文字が何個あるかを表示します。**

| 場所 | 出かた |
|---|---|
| 読み込みの候補一覧 | 名前の横に `⚠ XU`。**取り込む前**に気づけます |
| ライブラリ一覧 | 名前の横に `⚠ XU`。マウスを乗せると個数が出ます |
| 手入力・リンカーの追加 | 追加するときに知らせます |
| **出力タブ** | **警告バーが出て、配列の中の該当文字に波線が付きます** |

**止めません。警告だけです。** PDB から取った配列に `X` が入っていることは実際にあり、
止めてしまうと取り込めなくなるためです。直すかどうかはご自身で判断してください。

なお、**扱えない文字が含まれる配列の分子量は「およその値」**です（不明な残基を平均値で計算するため）。
その旨は出力タブに表示されます。

## 補足・制限

- 翻訳は標準遺伝暗号（NCBI table 1）のみ。イントロンやフレームシフトは扱いません
- SnapGene 独自形式（.dna）は未対応です。SnapGene から GenBank 形式で書き出してください
- `.ape` / GenBank の入手先は ApE 本体・Addgene・NCBI です。**PDB からは取得できません**（PDB は構造のデータベースで、プラスミドマップを持たないため）
- 分子量は平均質量から計算した理論値です
- 3D 構造の表示には対応していません
- 配列類似検索は廃止しました（貼り付けた配列が外部に送信されるため）
- ライブラリは端末ごとに独立です。別のマシンへ移すときはバックアップファイルを持っていってください
- PDB 検索と配列取得には `search.rcsb.org` と `data.rcsb.org` を使います。オフラインではこの 2 機能だけ使えません
- **外部に送信されるのは「検索語」と「PDB ID」だけ**です。ライブラリの配列も、設計中の配列も、読み込んだファイルも送信されません。ファイルの解析はすべてこの端末で行われます
