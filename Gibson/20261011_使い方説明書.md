# Gibson — 使い方説明書

作成日 2026-10-11 / 改訂 2026-10-12 / 対象: `Gibson.html`（作製 2026-10-12 12:50）

Gibson Assembly の反応の表（Vector・Insert の Volume、Master Mix、miliQ）を作り、
研究室の条件設定を満たしているかを判定する道具です。プライマーの Tm も計算できます。

---

## 1. 開き方

`Gibson.html` をダブルクリックしてブラウザで開きます。インストールもインターネット接続も要りません。
タブには青い「G」のアイコンが出ます。

画面の上部には、各区画へ移動するタブ（A. 反応の組み立て・B. Tm値の計算・C. 結果の出力・条件の保存・
修正リクエスト・自己テスト）が並びます。押すとその区画へ移動し、スクロールすると、いま見ている区画の
タブに青い下線が移ります。

## 2. 反応の表を作る（A. 反応の組み立て）

反応の全量は **20 µL** 固定、G.A. Master Mix は **2×（10 µL）** です。
Vector と Insert の Volume を決めると、残りが miliQ になります。

### 2.1 Volume を自分で入れる場合（「Volume を入力する」）

1. 「Insert の本数」を選びます（1〜5 本）。
2. 灰色の欄に、各断片の **Conc**（ng/µL）・**Length**（bp）・**Volume**（µL）を入れます。
3. Insert に名前を付けたいときは、行の先頭の欄に入力します（例: GFP）。
   空欄なら「Insert」（1 本のとき）、「Insert A」「Insert B」…（2 本以上のとき）になります。
4. 「**計算・判定**」を押します。

例（Vector 166 ng/µL・5238 bp・0.35 µL、Insert 100 ng/µL・308 bp・0.80 µL）:

|  | Conc | Length | pmol/µL | target pmols | Volume | 確認用 ng |
| --- | --- | --- | --- | --- | --- | --- |
| Vector | 166 | 5238 | 0.0488 | 0.0171 | 0.35 | 58.1 |
| Insert | 100 | 308 | 0.4995 | 0.3996 | 0.80 | 80 |
| G.A. M ×2 | | | | | 10 | |
| miliQ | | | | | 8.85 | |
| Total | | | | 0.4167 | 20 | |

- **確認用 ng** = Volume × その行の Conc です。
- 数字は「.35」「.8」のように 0 を省いて入れても、日本語入力のまま「。8」「０．８」と入れても読めます。

### 2.2 倍数から Volume を計算する場合（「倍数から計算する」）

Insert を Vector の何倍量（ng）入れたいかが決まっているときに使います。

1. 方式で「**倍数から計算する**」を選びます。表に「倍数」の列が出ます。
2. Vector は今までどおり Conc・Length・Volume を入れます。
3. 各 Insert は Conc・Length と**倍数**（例: 2.5）を入れます。
4. 「**計算・判定**」を押すと、Insert の Volume が自動で入ります。

Insert の Volume = Vector の ng（Volume × Conc）× 倍数 ÷ Insert の Conc を、0.01 µL 単位に丸めた値です。
丸めで少しずれるので、「計算確認」の表に目標の ng と実際の ng が並びます。判定は実際の ng で行います。

### 2.3 判定の見方

計算すると、表の下に判定の表（項目 / 目安 / 実際 / 判定）が出ます。
表の数字も色分けされます。

- **青字** … 条件設定を満たしている
- **赤字** … 満たしていない

色が付くのは、Volume（0.22 µL 以上か）、Vector の確認用 ng、Insert の確認用 ng（倍数）、Total の pmols です。

条件設定の中身は、A の上の方にある「**条件設定**」をクリックすると開いて見られます。

| 項目 | 目安 |
| --- | --- |
| Vector の量 | 50–100 ng |
| Insert / Vector（ng の比）、Insert 200 bp 以上 | ×2–3 |
| Insert / Vector（ng の比）、Insert 200 bp 未満 | ×5 以上 |
| 合計 pmol、2–3 fragment（Vector + Insert の数） | 0.02–0.5 pmol |
| 合計 pmol、4–6 fragment | 0.2–1.0 pmol |

このほか、各 Volume は 0.22 µL 以上（ピペットで取れる量）か判定します。
Vector と Insert の Volume の合計が 10 µL を超えるときは、計算せずにエラーを出します。

### 2.4 おすすめの Volume を使う

条件設定を満たす Volume を探してもらえます（「Volume を入力する」方式のとき）。

1. 各断片の **Conc と Length だけ**を入れます（Volume は空欄でよい）。
2. 「**おすすめの Volume**」を押します。
3. 提案の表が出ます。よければ「**この Volume を表に入れる**」を押すと、表に入って計算・判定されます。

- 条件をすべて満たす Volume があれば、必ずそれを提案します（「条件設定をすべて満たす Volume です。」）。
- すべては満たせないときは、Vector の量・合計 pmol・10 µL 以下・0.22 µL 以上を守り、
  Insert の倍数をできるだけ少なく下げた Volume を提案します。外れた倍数は赤字で出ます。
  短い Insert（例: 308 bp）と濃い Vector の組み合わせでは、計算上どうしても満たせないことがあります。
- どうしても作れないときは、満たせない条件が表示されます（例: Vector が濃すぎるので希釈）。

## 3. Tm を計算する（B. Tm値の計算）

1. 配列を 1 行に 1 本ずつ貼ります。空白・数字・小文字はそのままで構いません。
2. 「計算」を押すと、長さ・Tm・GC% が出ます。2 本以上なら Tm 差も出ます
   （3 本以上では、Tm が最大と最小の組の差）。

Tm はタカラバイオの簡易式 Tm(℃) = (A+T)×2 + (G+C)×4 − 5 で計算します。
この式の適用範囲は 25 mer 以下です。超える配列も値は出しますが、注意の列に「適用範囲外」と出ます。

## 4. 結果を残す（C. 結果の出力）

計算した区画（A・B）の結果をまとめて出せます。

- **Markdown でコピー** … 入力値・結果・判定・計算式をまとめてコピーします。実験ノート（Markdown）に
  そのまま貼れます。コピーした内容はボタンの下に表示されます。
- **印刷** … 表だけを 1 ページにまとめて印刷します（計算式などの文章は印刷しません）。

各区画は、最後に「計算・判定」「計算」を押したときの内容です。

## 5. 条件を保存する（条件の保存）

入力した値を保存しておき、あとで呼び出せます。

1. 必要なら名前を入れて、「**いまの条件を保存**」を押します。「保存した条件の一覧に No.1 として追加しました。」と出ます
   （No. は一覧での番号です）。
2. 「**保存した条件（n 件）**」をクリックすると一覧が開きます。
3. 「**読み込む**」で入力が戻ります。結果は保存していないので、読み込んだあと「計算・判定」を押してください。
4. 要らなくなったものは「削除」で消せます。

保存されるのは、方式・Insert の本数・名前・Conc・Length・倍数・Volume・Tm の配列です。

## 6. 修正を頼む（修正リクエスト）

ツールへの要望を Claude に伝えるための欄です。

1. 要望を書いて「**追加**」を押します。何件でもためられます（時刻が付きます）。
2. 「**まとめてコピー**」を押し、Claude との会話に貼り付けます。
3. 貼り終えたら「**一括削除**」で一覧を空にします（確認が出ます）。消し忘れると、次に同じ要望がもう一度送られます。

結果やエラーの内容を伝えたいときも、要望の欄に書いてください。

## 7. 計算を確かめる

上部の「自己テスト」タブ（ページの一番下）の「**自己テストを実行する**」を押すと、手計算した期待値と照合します。
すべて通過（169 件）すれば、計算は正しく動いています。失敗が出たら、その画面を修正リクエストで送ってください。

## 8. 困ったとき

| こんなとき | 原因と対処 |
| --- | --- |
| 「〜を入力してください」と出る | その欄が空欄です。メッセージに出ている欄を入れてください |
| 「…10 µL を超えるため計算しません」と出る | Vector と Insert の Volume の合計が 10 µL を超えています。Volume を減らすか、濃い DNA を用意してください |
| おすすめで倍数が赤字のまま | その濃度・長さの組み合わせでは、すべての条件を同時に満たす Volume がありません |
| 保存したリクエストや条件が消えた | ブラウザのサイトデータを消すと消えます。別のブラウザ・パソコンには引き継がれません |
| 「ブラウザに保存できませんでした」と出る | プライベートウィンドウなどで保存が禁止されています。その画面を閉じると消えます |
| コピーできない | 「下の欄を全選択してコピーしてください」と出たら、出てきた欄から手でコピーしてください |
| 古い倍数方式の保存を読み込むと Vector が空 | 2026-10-10 夕方より前の保存は形式が違います。Vector の Volume を入れ直してください |

## 9. 開発者向けメモ

- 画面を直したら `./build.sh` で `Gibson.html` を作り直します。部品が欠けるとビルドが失敗します。
- 部品は `gibson.js`（計算）と `parts/gibson/`（画面）です。詳しくは `20261011_仕様書.md` を見てください。
- `parts/shared/engine.js` は MutaPrimer と同じものです。MutaPrimer 側の Tm の式を直したら、
  こちらにも反映してください。
